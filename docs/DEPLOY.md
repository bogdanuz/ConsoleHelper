# Как выложить сайт самому (GitHub Desktop)

Сайт: **https://bogdanuz.github.io/ConsoleHelper/**  
Репозиторий: **bogdanuz/ConsoleHelper**

Делаешь всё ты через **GitHub Desktop**. Агенту пуш не нужен.

---

## Один раз: первый раз отправить код

1. Открой **GitHub Desktop**.  
2. Добавь этот проект (если ещё не добавлен): File → Add local repository → папка ConsoleHelper.  
3. Слева увидишь список изменённых файлов.  
4. Внизу слева напиши короткое сообщение, например: `Первый выпуск 0.6.0`.  
5. Нажми **Commit to main**.  
6. Нажми **Push origin** (отправить на GitHub).

Если Desktop спрашивает создать репозиторий на GitHub — выбери уже существующий `bogdanuz/ConsoleHelper` или опубликуй, как предложит.

---

## Один раз: включить сайт (Pages)

1. В браузере открой https://github.com/bogdanuz/ConsoleHelper  
2. **Settings** (Настройки) → слева **Pages**.  
3. В блоке **Build and deployment** → **Source** выбери **GitHub Actions**.  
4. Больше ничего выбирать не нужно.

---

## Каждый раз, когда хочешь обновить сайт

1. В GitHub Desktop сделай **Commit**.  
2. Нажми **Push origin**.  
3. На GitHub открой вкладку **Actions** — дождись зелёной галочки у **Deploy GitHub Pages** (обычно 2–5 минут).  
4. Открой https://bogdanuz.github.io/ConsoleHelper/ и обнови страницу (Ctrl+F5).

Если Pages включил **после** первого Push, а Actions уже красный или старый:
1. Actions → последний **Deploy GitHub Pages** → **Re-run all jobs**.

---

## Быстрая проверка после выкладки

1. Сайт открывается, видны шаги «Как начать» и блок «Что умеет меню».  
2. Скопируй закладку с сайта и сохрани в браузере.  
3. Открой обычную страницу с таблицей → нажми закладку → появилось меню.  
4. Сними таблицу → поправь в редакторе на той же странице → скачай Excel.

Если на Google Диске или похожем сайте снова «Не загрузилось» — это ограничение сайта. Напиши — сделаем запасной вариант закладки.

