# Что не попадает на GitHub

Файл в корне: `.gitignore`.  
Смысл: в репозиторий не уезжает мусор, секреты и то, что собирается заново.

## Не коммитим

| Что | Почему |
|-----|--------|
| `concept/` | черновые заметки и скриншоты — только локально (решение D9) |
| `fordelete/` | карантин вместо удаления — только на твоём диске |
| `node_modules/` | зависимости скачиваются через `npm install` |
| `dist/` | собранный сайт — появляется из `npm run build` |
| `.env`, ключи, пароли | секреты |
| логи, `.cursor/debug*.log` | отладка, не продукт |
| кэш Vite, coverage | временные файлы |
| ОС-мусор (`.DS_Store`, `Thumbs.db`) | только мешает |
| личные локальные заметки `*.local.*` | если появятся |
| `test-results/`, `playwright-report/` | артефакты e2e |
| `tmp/`, `*.bak` | черновики |

## Коммитим

Исходники, `public/tools/`, `public/vendor/`, `public/fat-bookmarklet.txt`, документация `docs/`, тесты, конфиги, `.cursor/rules` и `.cursor/skills`, `LICENSE`, `README`, опционально `ext/` (расширение — запасной путь).

## Если что-то «лишнее» уже не нужно

Не удаляем молча — перенос в `fordelete/` с датой и причиной. Папка `fordelete/` на GitHub **не** уезжает.
