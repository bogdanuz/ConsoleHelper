# Концепт ConsoleHelper

Дата: 2026-11-03 · продукт **v0.2.3**

## Одной фразой

**Сайт-каталог + закладка (без расширений) → клик на странице → меню → таблица в Excel.**

Для корпоративного Яндекс Браузера и других. Расширения на работе не используем.

## Ограничение

Без расширения нельзя «жить после F5 навсегда». Максимум: один клик по закладке после обновления; до обновления — Alt+Shift+H.

## Продукт

1. Закладка или сниппет (не расширение).  
2. Меню со всеми инструментами.  
3. Умная таблица (тумблер).  
4. Обезличенные демо в репо.

См. [DECISIONS.md](DECISIONS.md).
