# Чеклист проверки 0.11.0 (после деплоя)

Боевой сайт: https://bogdanuz.github.io/ConsoleHelper/

Отмечай галочкой по ходу. Если что-то красное — напиши, на каком шаге.

## 0. Перед проверкой

- [ ] GitHub Desktop → Push выполнен
- [ ] Actions зелёный (Pages задеплоился)
- [ ] Страница обновлена жёстко (Ctrl+F5)

## 1. Сайт ConsoleHelper

- [ ] Шаги «Как начать»: Начать → Скопировать → Продолжить → закладка → открыть меню
- [ ] Секция **Failed to fetch** видна
- [ ] «Скопировать полную закладку» → статус «Скопировано…»
- [ ] В каталоге 4 карточки с блоками «Что делает» / «Когда брать»
- [ ] Поиск по каталогу что-то находит и умеет «Ничего не найдено»

## 2. Обычная закладка на любой странице

- [ ] Закладка открывает меню
- [ ] Под пунктами есть серые подсказки
- [ ] Alt+Shift+H снова открывает меню без обновления страницы
- [ ] Esc закрывает меню (кликни вне поиска и нажми Esc)

## 3. Текст → таблица

- [ ] «Область» / «Страница уже вся загружена» открывают редактор
- [ ] Есть кнопки прокрутки и текст «Не уверен?»
- [ ] Фильтр оставляет нужные строки; «Сбросить фильтр» возвращает всё
- [ ] «Только непустые» становится **Непустые: ВКЛ**
- [ ] Клик по числу → сумма; ✕ строки → сумма остаётся на том же числе
- [ ] Двойной клик → правка ячейки; Enter сохраняет
- [ ] Excel скачивает `.xlsx` (или пишет про запасной `.xls`)

## 4. Найти таблицы / Карточки

- [ ] Найти таблицы: подсветка → открытие редактора → Excel
- [ ] Карточки → таблица: «Вся видимая зона» или область → «Найдено карточек: N»
- [ ] Если 0 карточек — понятный alert

## 5. Скриншот (только обычная закладка)

- [ ] «Страница уже вся загружена» → PNG не белый
- [ ] «Список подгружается при прокрутке» → прогресс «Прокрутка …» → PNG
- [ ] «Выделить область» работает

## 6. Полная закладка (строгий сайт / Failed to fetch)

- [ ] Полная закладка открывает меню с пометкой «Полная закладка»
- [ ] Текст→таблица / Найти таблицы / Карточки работают без fetch меню
- [ ] Скриншот пишет, что нужен обычный вариант
- [ ] Excel с полной закладки всё же качает файл (подтягивает библиотеку с сайта ConsoleHelper)

## Готово, если

Все галочки зелёные → волна B в бою ок.  
Красное → номер шага + что увидел на экране.
