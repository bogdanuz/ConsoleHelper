# Версии (SemVer) — простыми словами

Формат: **MAJOR.MINOR.PATCH** (сейчас **0.6.0**).

| Часть | Когда меняем | Пример для тебя |
|-------|----------------|-----------------|
| **PATCH** (0.1.1) | мелкая правка, баг, текст | «починили кнопку копирования» |
| **MINOR** (0.2.0) | новая возможность, старое не ломаем | «добавили схлопывание строк» |
| **MAJOR** (1.0.0) | первый «можно пользоваться каждый день» или ломающее изменение | «официальный запуск» |

Пока версия **0.x** — продукт в сборке, можно менять поведение смелее.

## Где хранится

- `package.json` → поле `"version"`
- `docs/CHANGELOG.md` → история
- При релизе на Pages — тег git `v0.1.0` (через GitHub Desktop / сайт), по желанию

## Правило агента

- Любой завершённый спринт или заметный кусок работы → запись в CHANGELOG.
- Релиз на сайт → поднять версию + секция в CHANGELOG не `[Unreleased]`, а `[x.y.z] — дата`.
