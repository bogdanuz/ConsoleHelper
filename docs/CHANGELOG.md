## [0.11.1] — 2026-11-03

### Fixed

- Esc закрывает меню, редактор и панели инструментов (не только поле поиска).
- Умная таблица: при переносе «название + код» добавляется колонка для всех строк — числа не съезжают вбок.
- В редакторе строка «Выбрано: 0 · сумма» всегда видна (фильтр/сумма не «пропали»).

## [0.11.0] — 2026-11-03

### Added

- Полная закладка + секция «Что делать, если Failed to fetch?» (таблицы без fetch; скриншот — только обычная закладка).
- Table Studio: фильтр строк, выделение кликом, сумма выбранных ячеек.
- Настоящий Excel `.xlsx` (SheetJS в `public/vendor/`).
- Инструмент «Карточки → таблица» + подсказки в меню/каталоге.
- Съём: режимы «страница уже загружена» / «подгрузка при прокрутке» (+ автопрокрутка).
- Чеклист боя: `docs/CHECKLIST-0.11.md`.

### Fixed

- Редактор: двойной клик снова открывает правку ячейки (клик больше не пересобирает таблицу).
- Редактор: после удаления строки сумма/выделение не «прыгают» на чужие ячейки.
- Полная закладка: прописан адрес ConsoleHelper для Excel (`.xlsx`) на чужих сайтах.
- Меню и каталог на сайте: подписи без опасной вставки HTML.
- Текст→таблица: после автопрокрутки сначала съём текста, потом возврат вверх.
- Текст→таблица / Найти таблицы: перед новым редактором старый корректно закрывается.
- Карточки→таблица: если `.xlsx` не загрузился — запасной `.xls` и статус на экране.
- Редактор: кнопка «Непустые: ВКЛ» и подсказка, если строк больше 500 на экране.
- Меню: Esc закрывает окно с любого фокуса.
- Автопрокрутка: Esc реально останавливает прокрутку (скриншот и текст→таблица).
- Скриншот не захватывает панель «Карточки».
- После скачивания Excel/CSV освобождается временная ссылка в памяти.
- Закладка: обёртка `void(...)` и проверка HTTP.
- Launcher: не `eval` при ошибке загрузки tool.

### Changed

- README и тексты сайта простым языком.
- Убран отдельный редактор/вставка на сайте и пункт «Вставить из буфера» (в `fordelete/`, локально).
- `.gitignore`: `fordelete/` и отладочные логи не уезжают на GitHub.

## [0.6.1] — 2026-11-03

## [0.2.1] — 2026-11-03
