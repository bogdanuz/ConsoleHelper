# Аналитика функционала ConsoleHelper

Дата: **2026-11-03** · этап 1 (без разработки кода инструментов)  
Статус согласования приоритетов: **приняты** (см. D12 в DECISIONS.md)

## Карта текущего

```
Закладка/сниппет → Меню (launcher)
  ├─ Текст → таблица → Table Studio (правка) → Excel/CSV/TSV
  ├─ Найти таблицы → подсветка → Table Studio → Excel/CSV/TSV
  └─ Скриншот → html2canvas (CDN) → PNG
```

| Инструмент | Файл | Роль |
|------------|------|------|
| Меню | `public/tools/launcher.js` | Поиск и запуск |
| Текст → таблица | `public/tools/text-to-table.js` | Съём + склейка + Table Studio + экспорт |
| Table Studio | `public/tools/table-studio.js` | Правка ячеек, удаление строк, вставка из буфера |
| Вставка в Studio | кнопка в `table-studio.js` | Ctrl+V / «Вставить» уже в редакторе на странице |
| Найти таблицы | `public/tools/dom-tables.js` | DOM → Table Studio + экспорт |
| Скриншот | `public/tools/screenshot.js` | Fullpage PNG |

Хаба: онбординг закладки + каталог — ок для старта.

## Плюсы

- Без расширений (корпоративный Яндекс Браузер).
- Один вход → всё меню.
- «Текст → таблица» закрывает главную боль кривых сеток.
- «Найти таблицы» удобен на настоящих `<table>`.
- Есть Excel/TSV.

## Минусы и поломки

### Скриншот

- CDN html2canvas часто блокируется → файл не скачивается.
- Нет понятного статуса ошибки.
- Fullpage на SPA нестабилен; нет «область» / «видимое окно».

### Текст → таблица

- Превью только просмотр (нет правки ячеек/строк).
- Мало форматов (нет CSV / нормального xlsx).
- Сложные px-настройки; виртуальный скролл не покрыт.

### Найти таблицы

- Слабо на кастомных гридах.
- Нет общего редактора с «Текст → таблица».

### Общий UX tools

- Стиль панелей не как у хаба.
- Нет единого окна результата.

## Идея Table Studio

Одно окно после любого съёма:

1. Источник: область / DOM / буфер.  
2. Правка ячеек кликом.  
3. Удаление строк; позже сдвиг строк/колонок.  
4. Умная склейка / пустые.  
5. Экспорт TSV, CSV, Excel (xlsx позже).

**MVP редактора:** правка ячеек + удаление строк + экспорт — **без** drag-and-drop колонок в первой волне.
