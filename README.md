# ConsoleHelper

**Версия 0.6.0** · [MIT](LICENSE)

Сайт: https://bogdanuz.github.io/ConsoleHelper/

## Что это

Помощник для таблиц в браузере: открыл меню на странице → забрал данные → скачал Excel.

Ставится как обычная **закладка**, без установки программ в браузер. Один раз настроил — на странице с таблицей нажал закладку — справа открылось меню.

Из меню можно:
- снять таблицу с экрана и поправить;
- найти готовые таблицы на странице;
- сделать скриншот;
- скачать в Excel или скопировать дальше.

Подходит для Яндекс Браузера, Chrome, Edge.

## Как начать

1. Открой сайт выше.  
2. Пройди короткие шаги и скопируй команду.  
3. Сделай закладку ConsoleHelper: в адрес закладки вставь то, что скопировал.  
4. Зайди на страницу с таблицей и нажми эту закладку (не открывай её пустой вкладкой).  
5. В меню выбери инструмент — редактор откроется **на этой же странице**.
