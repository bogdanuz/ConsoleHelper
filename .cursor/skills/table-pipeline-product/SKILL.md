# Table pipeline (product)

1. **Взять** — область, DOM-таблица или вставка.
2. **Почистить** — умная таблица (normalize), по умолчанию вкл.
3. **Показать** — превью с тумблером «как есть».
4. **Скачать** — Excel / TSV / CSV.

Always keep raw path available. Speak in user stories.
