# ConsoleHelper — мини-расширение (опционально)

Нужно, если можно ставить расширения. Даёт **Alt+Shift+H** на любой вкладке без DevTools и без повторного запуска.

## Установка

1. Открой `chrome://extensions` → Режим разработчика.
2. «Загрузить распакованное» → папка `ext/`.
3. В `background.js` замени `CHANGE_ME` на свой логин GitHub (или URL Pages).

Если расширения на компьютере запрещены — используй путь **userscript (Tampermonkey)** с сайта ConsoleHelper: он тоже живёт постоянно.
